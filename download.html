Install in 5 steps

  1. Tap Download APK above in Chrome on your Android phone.
  2. When the download finishes, tap the notification, or open Files → Downloads and tap the WayStation file.
  3. If Android says Chrome isn't allowed to install apps, tap Settings, turn on Allow from this source, then go back.
  4. Tap Install. If Play Protect asks, tap Install anyway. It asks because WayStation isn't in the Play Store yet.
  5. Open WayStation and link your email. See the tutorials for each provider.

Updating

New versions are posted here and on the changelog. Download the new file and install it over the old one. Your linked accounts and vault stay.

Already have an older test build?

Uninstall it first, then install this version. Test builds and public builds are signed differently, so Android won't install one over the other.
