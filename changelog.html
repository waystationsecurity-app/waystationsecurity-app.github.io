Signing

Every WayStation APK is signed with the same key. Before installing, check that the APK's signing certificate matches this fingerprint:

SHA-256: 5E:22:FD:9C:49:ED:B5:CA:51:8A:23:6D:16:BF:56:9A:C3:5C:2B:65:BB:3A:90:50:B4:75:FD:7F:E9:F2:D1:BE

Certificate subject: C = US, O = Android, CN = Android Debug. The download page lists the SHA-256 hash of the APK file itself — that catches a corrupted download. This certificate fingerprint is the cross-check against a tampered one: a swapped APK signed with a different key will not match it.
